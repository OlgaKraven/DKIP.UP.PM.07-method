# Документация команд

Методичка содержит обязательные шаги целиком. Эти ссылки служат для уточнения возможностей выбранной версии, а не для поиска пропущенного этапа.

- [MySQL 8.0: GRANT](https://dev.mysql.com/doc/refman/8.0/en/grant.html) — область привилегий.
- [MySQL 8.0: mysqldump](https://dev.mysql.com/doc/refman/8.0/en/mysqldump.html) — параметры, формат и result-file.
- [MariaDB: mariadb-dump](https://mariadb.com/docs/server/clients-and-utilities/backup-restore-and-import-clients/mariadb-dump) — дамп своей СУБД.
- [PostgreSQL 16: роли](https://www.postgresql.org/docs/16/role-attributes.html), [pg_dump](https://www.postgresql.org/docs/16/app-pgdump.html), [pg_restore](https://www.postgresql.org/docs/16/app-pgrestore.html).
- [SQL Server: сжатие копий и поддерживаемые редакции](https://learn.microsoft.com/en-us/sql/relational-databases/backup-restore/backup-compression-sql-server?view=sql-server-ver16).
- [SQL Server Express: запуск резервирования по расписанию](https://learn.microsoft.com/en-us/troubleshoot/sql/admin/schedule-automate-backup-database).
