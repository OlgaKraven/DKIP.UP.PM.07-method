# Учебная практика ПМ.07 «Соадминистрирование и автоматизация баз данных и серверов»

Комплект методических материалов для учебной практики по ПМ.07.

Итоговая работа практики: **виртуальная машина с установленной СУБД и сервером**, на которой студент выполняет базовые задачи администратора и пишет **один скрипт автоматизации** рутинной операции (резервная копия, перезапуск, проверка свободного места).

Обязательные результаты:

- установленная и работающая СУБД (MySQL, MariaDB, PostgreSQL или MS SQL Server Express — по варианту);
- набор пользователей с разными ролями (`admin`, `app_user`, `readonly`);
- ручной бэкап и восстановление с проверкой;
- скрипт автоматизации (Bash или PowerShell) для одной рутинной задачи;
- запуск скрипта по расписанию (cron или Планировщик заданий Windows);
- журнал администратора с описанием каждой выполненной операции.

Материалы оформлены как методический сайт MkDocs. Теория объясняет, что и зачем делается. Практика — пошаговая последовательность команд для основных СУБД и ОС.

## Состав

- `docs/index.md` — главная: цель, задачи, требования.
- `docs/subject_areas.md` — 30 вариантов (СУБД × ОС × предметная область × автоматизация).
- `docs/theory/stage1-4.md` — теоретические материалы по этапам.
- `docs/practice/stage1-4.md` — практические этапы выполнения.
