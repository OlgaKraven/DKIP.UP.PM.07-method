# Подготовка текстов и PDF

Учебные исходники находятся в `docs/`. Общая постановка — `index.md`, объяснения — `practice/` и `theory/`, шесть самостоятельных последовательностей — `routes/`, тридцать вариантов — `subject_areas.md`. SQL в `downloads/variant-NN.sql` — входные учебные данные, а не проверенный результат выполнения практики.

Для PDF используется `tools/build_materials.cjs`: он читает эти Markdown, применяет сохранённый дизайн и сохраняет `docs/downloads/assignment.pdf` и `guide.pdf`. HTML просмотра и промежуточные материалы находятся в игнорируемом `work/`. Отдельного источника учебного содержания в JSON нет.

Нужны доступные Node.js, marked и Playwright; можно использовать уже установленный рабочий runtime через NODE_PATH. Сборщик ничего не устанавливает и не запускает СУБД или планировщик. Команда: `node tools/build_materials.cjs`. Утилита `tools/check_materials.py` сверяет входные ссылки, варианты, текст, шрифты и геометрию PDF.

Уточнение пользователя от 04.11.2026: исключение без работы на компьютере относится только к Unity. Для этой практики нужны также фактические проверки действий в подготовленных средах. Наличие листингов и PDF не подтверждает их выполнение.
